# 🏨 Hotel Management System (Java)

This is a **Hotel Management System** built entirely using **Java**. The system provides core hotel operations such as booking rooms, checking in/out, managing customers, and billing — all within a simple and user-friendly interface.

## 🚀 Features

- 🧾 Room Booking & Cancellation
- 🙍 Customer Check-in / Check-out
- 🛏️ Room Availability Display
- 💳 Bill Calculation
- 🗂️ Customer Records Management
- 🧼 Room Services (Optional Feature)

## 🛠️ Technologies Used

- **Java SE** (Core Java)
- **OOPs Concepts**: Inheritance, Polymorphism, Encapsulation
- **File Handling** (for data persistence)
- **Collections Framework** (e.g., ArrayList, HashMap)
